## Cómo interpretar la documentación

- La existencia de un documento no demuestra que una función esté terminada.
- Los estados de las HUs deben contrastarse con código, pruebas y evidencias.
- Los documentos pendientes se muestran sin enlaces hasta que existan.
- Las validaciones del equipo se registrarán cuando realmente se realicen.
