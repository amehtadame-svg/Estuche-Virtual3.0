# CU22 - Eliminar producto

## Descripción

Eliminar producto

## Actores

- Administrador

## Precondiciones

- El usuario debe haber iniciado sesión.

## Postcondiciones

- La información queda registrada en el sistema.

## Flujo principal (Secuencia Normal)

1. **Acción (actor):** Seleccionar  
   **Reacción (sistema):** El sistema procesa: Seleccionar
2. **Acción (actor):** Eliminar  
   **Reacción (sistema):** El sistema procesa: Eliminar

## Flujo alternativo (Excepciones)

1. **Acción (actor):** Confirmación  
   **Reacción (sistema):** El sistema muestra: Confirmación
