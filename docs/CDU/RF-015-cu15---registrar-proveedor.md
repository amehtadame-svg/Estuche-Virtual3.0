# CU15 - Registrar proveedor

## Descripción

Guardar proveedor

## Actores

- Administrador

## Precondiciones

- El usuario debe haber iniciado sesión.

## Postcondiciones

- La información queda registrada en el sistema.

## Flujo principal (Secuencia Normal)

1. **Acción (actor):** Ingresar datos  
   **Reacción (sistema):** El sistema procesa: Ingresar datos
2. **Acción (actor):** Guardar  
   **Reacción (sistema):** El sistema procesa: Guardar

## Flujo alternativo (Excepciones)

1. **Acción (actor):** Error en datos  
   **Reacción (sistema):** El sistema muestra: Error en datos
