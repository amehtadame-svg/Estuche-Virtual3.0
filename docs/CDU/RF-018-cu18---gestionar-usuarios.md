# CU18 - Gestionar usuarios

## Descripción

Crear roles

## Actores

- Administrador

## Precondiciones

- El usuario debe haber iniciado sesión.

## Postcondiciones

- La información queda registrada en el sistema.

## Flujo principal (Secuencia Normal)

1. **Acción (actor):** Crear usuario  
   **Reacción (sistema):** El sistema procesa: Crear usuario
2. **Acción (actor):** Asignar rol  
   **Reacción (sistema):** El sistema procesa: Asignar rol

## Flujo alternativo (Excepciones)

1. **Acción (actor):** Error  
   **Reacción (sistema):** El sistema muestra: Error
