# CU12 - Crear combos

## Descripción

Agrupar productos

## Actores

- Administrador

## Precondiciones

- El usuario debe haber iniciado sesión.

## Postcondiciones

- La información queda registrada en el sistema.

## Flujo principal (Secuencia Normal)

1. **Acción (actor):** Seleccionar productos  
   **Reacción (sistema):** El sistema procesa: Seleccionar productos
2. **Acción (actor):** Guardar combo  
   **Reacción (sistema):** El sistema procesa: Guardar combo

## Flujo alternativo (Excepciones)

1. **Acción (actor):** Error en selección  
   **Reacción (sistema):** El sistema muestra: Error en selección
