# CU19 - Iniciar sesión

## Descripción

Acceso al sistema

## Actores

- Vendedor

## Precondiciones

- El usuario debe haber iniciado sesión.

## Postcondiciones

- La información queda registrada en el sistema.

## Flujo principal (Secuencia Normal)

1. **Acción (actor):** Ingresar credenciales  
   **Reacción (sistema):** El sistema procesa: Ingresar credenciales

## Flujo alternativo (Excepciones)

1. **Acción (actor):** Datos incorrectos  
   **Reacción (sistema):** El sistema muestra: Datos incorrectos
