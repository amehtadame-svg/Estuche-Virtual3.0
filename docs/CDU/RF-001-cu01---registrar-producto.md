# CU01 - Registrar producto

## Descripción

Permite agregar productos al inventario.

## Actores

- Administrador

## Precondiciones

- El usuario debe haber iniciado sesión.

## Postcondiciones

- La información queda registrada en el sistema.

## Flujo principal (Secuencia Normal)

1. **Acción (actor):** Ingresar datos  
   **Reacción (sistema):** El sistema procesa: Ingresar datos
2. **Acción (actor):** Guardar producto  
   **Reacción (sistema):** El sistema procesa: Guardar producto

## Flujo alternativo (Excepciones)

1. **Acción (actor):** Error si faltan datos  
   **Reacción (sistema):** El sistema muestra: Error si faltan datos
