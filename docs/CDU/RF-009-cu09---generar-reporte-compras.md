# CU09 - Generar reporte compras

## Descripción

Reporte de compras

## Actores

- Administrador

## Precondiciones

- El usuario debe haber iniciado sesión.

## Postcondiciones

- La información queda registrada en el sistema.

## Flujo principal (Secuencia Normal)

1. **Acción (actor):** Seleccionar fechas  
   **Reacción (sistema):** El sistema procesa: Seleccionar fechas
2. **Acción (actor):** Generar  
   **Reacción (sistema):** El sistema procesa: Generar

## Flujo alternativo (Excepciones)

1. **Acción (actor):** Sin datos  
   **Reacción (sistema):** El sistema muestra: Sin datos
